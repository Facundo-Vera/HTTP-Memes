<h1 align="center" style="font-size: 4rem;">😂 STATUS MEME</h1>

**Status Meme** es una aplicación web que muestra los **HTTP Status Codes** representados como memes, combinando humor y aprendizaje para desarrolladores y estudiantes.

La idea es entender qué significa cada código de estado de forma rápida, visual y entretenida.

---

## 🚀 Características

- 📚 Códigos HTTP (100 – 500)
- 😂 Memes explicativos por cada status
- ⚡ Renderizado eficiente con React
- 📱 Diseño responsive
- 🎨 Estilos modernos con Tailwind CSS

---

## 🛠️ Tecnologías utilizadas

- React
- JavaScript (ES6+)
- Tailwind CSS
